# Artwork

This folder contains the source [TouchDesigner file](main.toe), used to generate the artwork for **Fully Automated Luxury Music**. It is based on a [source image](media/img.png) generated with the _Gemini Pro 3_ model via [RunwayML](https://app.runwayml.com/), using the following text prompt:

> An abstract geometric vortex of orchestral instruments and synthesizers. The color palette is midnight blue, blacks, and some pinkish reds

The [image](media/img.png) used is not the original output, but a manually edited version of that initial image, mostly involving upscaling, sharpening, and color grading.

> **NOTE**: The image is not included in the repo, but should be automatically downloaded and placed in the [media](/media) folder when setting up the environment via the [setup.py](../setup.py) script.
